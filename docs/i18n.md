# 多語系（i18n）架構與「新增語言」指南

> 2026-07 英文版開發累積的完整知識。之後要加日文、韓文等，照本文件走可省掉 90% 的踩坑時間。

## 架構總覽（web/js/i18n.js）

採「**事後翻譯層**」：介面文案照舊寫中文，`tt_lang` 不是 `zh` 時由翻譯層把畫面上的文字換掉。

| 元件 | 作用 |
|------|------|
| `DICT` | 中文字串（key）→ 譯文（value）的字典，~550 條。**中文原文就是 key**，所以加新語言＝同一組 key 配一份新字典 |
| `PATTERNS` | 規則式翻譯 ~100 條：處理含數字/名字的組合句（`5 分鐘前`、`○○ 開始追蹤你`、`還差 X km`）。regex + 函式，可在函式裡呼叫 `tx()` 翻內層內容、回傳 `null` 表示不處理 |
| `tx(s)` | 翻譯入口：trim → 沒中文直接跳過 → 查 DICT → **句尾標點正規化**（剝 `。．）：` 再查，補回英文標點）→ 跑 PATTERNS |
| `walk(root)` | TreeWalker 掃文字節點 + `placeholder/title/aria-label` 屬性做替換 |
| `start()` | 開機翻整頁 + MutationObserver 監聽（childList + characterData），動態面板/toast 也會被翻 |
| `ttLocale()` | 回傳 `en-US`/`zh-TW`，全站 `toLocale*String(ttLocale())` 用（日期、時間、AM/PM） |
| `ttT(s)` | 給 **canvas / 純 JS 產字**用（分享圖卡）：DOM 觀察器碰不到的文字在產生時就翻 |
| `ttTranslate(text, target)` | 使用者內容的機器翻譯（翻譯年糕）：Google 免金鑰端點 → MyMemory 後備，兩層快取（記憶體 + localStorage `tt_tr_cache` 各 120 筆） |

語言切換 UI 在「我的 → 外觀主題 → 語言 Language」（`.lang-opt`，存 `tt_lang` 後 reload）。

## 守門機制（別讓翻譯再破洞）

- `scripts/check.js` **規則 H**：掃全部 JS 模板的中文字串 → 逐一過 `tx()` → 翻不出又不在 `scripts/i18n-ignore.json` 就**擋 commit**。
- `scripts/i18n-ignore.json`：刻意不翻的清單（~99 條）——資料值、除錯面板、品牌名、模板片段誤報。新增「確實不用翻」的字串時加進這裡並想清楚原因。
- `scripts/tests/test-fixes.js` 有 i18n 單元測試（字典/規則抽查），`npm run check` 自動跑。

## 新增一個語言的步驟（以日文 ja 為例）

1. **i18n.js 結構調整**（一次性）：把 `DICT`/`PATTERNS` 包成 `const LANGS = { en: { DICT, PATTERNS }, ja: { DICT: {...}, PATTERNS: [...] } }`，`tx()` 依 `lang()` 取表。`ttLocale()` 加 `ja → "ja-JP"`。
2. **產生翻譯底稿**：跑一段 node 腳本把 `en.DICT` 的 key 全部倒出來（中文原文清單），交給翻譯（人工或 LLM 批次），做成 `ja.DICT`。
3. **PATTERNS 逐條移植**：規則的 regex（左邊）不變（比對的是中文原文），只改右邊的輸出模板。約 100 條，半天工。
4. **語言切換 UI**：index.html `#langRow` 加一顆 `data-lang-opt="ja"` 按鈕。
5. **canvas/分享文字**：`ttT()` 自動跟著新字典走；`shareHikeCard`/`drawYearImage`/年度分享文字裡有幾處 `I18n.lang() === "en" ? ... : ...` 的三元式要改成查表。
6. **驗證**：`node scripts/check.js`（規則 H 對新字典跑覆蓋）＋ 手機實測。

## 踩過的坑（新語言一定會再遇到，先讀）

1. **句尾標點**：詞條「尚無貼文」對不上畫面「尚無貼文。」→ `tx()` 已做正規化（`。．）：`），新字典 key 一律**不含**句尾標點。
2. **模板碎片**：`已走 <b>${km}</b> km` 會被 `<b>` 切成三個文字節點——「已走」「數字」「km」。碎片要各自有詞條，或改用整節點 PATTERNS。盤點工具撈到的「半句」多半是這種。
3. **emoji 開頭**：「😊 剛運動完…」「🛤 泥土」exact key 對不上 → 已有**通用規則**（emoji 前綴剝掉、內文再翻），新語言直接繼承。
4. **黏在一起的組合節點**：「3 小時前 · 好友」「NT$60 / 月」「適合：…　·　…　·　…」都是單一節點，只能用 PATTERNS。
5. **canvas 畫的字**（分享圖卡）：DOM 觀察器碰不到，文字產生處要用 `ttT()` 包。
6. **原生對話框翻不了**：`confirm/prompt/alert` 是瀏覽器畫的。現存清單：清空全部行程、雲端還原合併/取代、下載全台確認、編輯內文、退出小隊、封鎖確認、無 GPS 提示。要根治＝換自製面板（優化清單既有項目）。
7. **日期時間不是翻譯是 locale**：一律 `toLocale*String(ttLocale())`，別寫死 `"zh-TW"`（規則 H 管不到這個，寫碼時自己注意）。語音辨識的 `zh-TW` 與天氣 API 的 `Asia/Taipei` **不要**改。
8. **資料 vs 介面**：步道名稱/介紹/地區/路況公告是資料，不進字典；長文用「Translate」按鈕（`ttTranslate`）機翻。但**資料裡的有限枚舉值要翻**：路面（泥土/木棧道…）、季節（四季皆宜…）、時程（半天/一天…）、難度標籤——已在字典。
9. **規則順序**：PATTERNS 由上往下第一個命中就用——精確規則放前面，泛用（如 emoji 前綴）放最後。
10. **含 `>` `/` 的字串**：盤點 regex 會跳過（雜訊過濾），這類字串（如「>20km/h」「匯出/匯入」）得手動確認有詞條。
11. **單字 key 要小心**：「步」「天」「篇」「日一二三四五六」這種單字詞條可能誤傷其他節點，加之前想一下哪裡會出現同字。
12. **自訂內容不翻**：使用者取的寵物名、handle、暱稱保留原樣；只有「未命名時的預設值」（階段名等）才翻。
13. **⚠️ 同形詞條會引爆無限迴圈（v241 白屏事故）**：日文這類漢字語言必有「譯文＝原文」的詞條（設定→設定、時間→時間）。把文字節點**寫回相同值仍會觸發 MutationObserver** → 再翻 → 再寫 → 無限微任務迴圈，整頁凍結；語言偏好持久化後重開即白屏。walk()/observer 的**所有賦值都必須「同值不寫回」**（已內建，改動翻譯層時千萬別拿掉）。加漢字語言（韓文漢字詞、日文）務必實機測過再發。

## 語言現況

- **en**（英文）：字典 ~970 條＋規則 ~105 條，全介面覆蓋。
- **es**（西班牙語，2026-07-03 加入）：與 en 完全平行。製作流程＝本文件「新增語言步驟」的實踐：
  機翻底稿（scratchpad/build-es.mjs 用 Google 端點英→西批次產生）→ 人工校正 172 條關鍵詞
  （scratchpad/curate-es.mjs 的 FIX 表：短詞如 儲存→Guardar 非 Ahorrar、貼文→Publicación 非 Correo、
  陣雨→Chubascos 非 Duchas、週字 D/L/M/X/J/V/S）→ 手寫 ES_PATTERNS 全集 → check.js H2 驗平行性。
- 結構：`LANGS = { en: {D, P}, es: {D, P} }`；`tx()` 依 `tt_lang` 取表（zh 或未知語言以 en 為檢查基準）；
  `ttLocale()`/`ttTrTarget()` 每語言各補一個 mapping；index.html `#langRow` 一顆按鈕。
- **ja**（日本語，2026-07-03 加入）：同一條生產線第三次實踐（機翻底稿 build-ja.mjs → 297 條人工校正 curate-ja.mjs → 手寫 JA_PATTERNS 119 條）。**日文特例：不載地名字典**——台灣步道/縣市的漢字名日文使用者直接可讀，tx() 的地名後備與 start() 的載入都跳過 ja。翻譯年糕在日文叫「ほんやくコンニャク」。
- **ko/fr/de**（韓/法/德，2026-07-04）：同一條生產線（build-lang.mjs 英→目標機翻底稿 → curate-langs.mjs 各 ~100 條關鍵詞校正 → 手寫 PATTERNS 119 條）。載羅馬拼音地名字典（同 en/es）。
- **cn**（簡體中文，2026-07-04）：繁→簡（build-lang.mjs sl=zh-TW tl=zh-CN，含詞彙差異 軟體→软件/貼文→帖子）。**不載地名字典**（漢字直讀，同 ja）。⚠️ 簡中同形詞比例最高，是第 13 坑（同形詞無限迴圈）最嚴苛的考驗——已過 E2E 凍結回歸。
- **check.js 規則 H2**：en 的 key 其他語言缺了、或規則數不一致 → 擋 commit（永保各語言同步）。
