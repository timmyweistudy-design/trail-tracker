# 步道生態資訊 設計（2026-07-17）

## 目標

在步道詳情頁新增「生態」區塊,讓使用者出發前知道:
1. **蚊蟲警示**——尤其小黑蚊/一般蚊子的出沒風險與防護建議(使用者明確要求)。
2. **常見動植物**——這條步道所在環境帶常會遇到的代表性動物、昆蟲、鳥類。
3. **(有網路時)真實目擊**——附近的 iNaturalist 近期觀察記錄。

核心原則:**離線可用**(山區沒訊號時生態資訊最有用,是本 App 核心賣點)、**誠實標示**(規則式內容標「這個海拔帶常見」,不謊稱「這條步道記錄到 X」)、**零 API 依賴的底層**(連網只是加分)。

## 資料來源決策

採**混合方案**:規則式為底(離線、涵蓋全部 2000+ 步道)+ 選配連網補真實目擊(iNaturalist)。

兩個已拍板的決策:
- **物種名維持中文**(可附學名),不翻 25 語言——與現有「步道資料維持中文、只翻介面」的 i18n 策略一致;台灣物種中文名是山友慣用。
- **簡潔實用版**——警示 + 常見清單 + 選配目擊,貼合現有詳情頁風格,不做厚重圖鑑。

## 資料架構

### 環境帶對照表(離線底層)

不為每條步道存物種清單(會爆資料量)。改用「環境帶 → 代表物種」對照表,步道在 runtime 依自己的**海拔 + 地區 + 標籤/水系**對應到一個或多個環境帶。

環境帶(初版):

| 環境帶 | 判定條件 | 代表物種(舉例,每帶 10–20 種) |
|---|---|---|
| 低海拔闊葉林 | 海拔 < 800m | 台灣獼猴、赤腹松鼠、五色鳥、台灣藍鵲、鳳蝶、獨角仙、攀木蜥蜴 |
| 中海拔針闊混合林 | 800–2500m | 山羌、白面鼯鼠、帝雉、金翼白眉、鍬形蟲 |
| 高山 | > 2500m | 台灣水鹿、岩鷚、酒紅朱雀、雪山草蜥 |
| 溪流/瀑布 | 有水系標籤或名稱含溪/瀑 | 台灣紫嘯鶇、鉛色水鶇、豆娘、蜻蜓、澤蟹 |
| 海岸 | 近海(低海拔+沿海地區) | 招潮蟹、彈塗魚、海濱植物 |

- 物種集合基於台灣生態常識(各海拔帶代表種),不是特定步道的觀察記錄——呈現時明確標示。
- 一條步道可命中多個環境帶(如低海拔+溪流),物種取聯集、去重。
- 資料檔 `web/js/ecology.js`,幾十個環境帶 × 每帶 10–20 種,資料量小、全離線。

### 蚊蟲風險(純函式計算)

小黑蚊(台灣鋏蠓)分布本就是海拔/地區/季節的函數,規則式最準,不需觀察資料。

因子:
- **海拔**:< 500m 高風險、500–1000m 中、> 1000m 幾乎無(小黑蚊上不了高山)。
- **地區**:中南部、花東 > 北部(權重加成)。
- **季節**:3–10 月活躍(尤其 5–9 月);依使用者**當下日期**動態顯示——非當季則降級提示。
- **環境**:竹林/樹蔭/溪邊加成。

輸出:`{ level: "high"|"mid"|"low"|"none", tips: [...], seasonal: bool }`
- 等級對應色塊(高🔴/中🟡/低🟢)。
- 防護建議:長袖長褲、防蚊液(敵避 DEET/派卡瑞丁)、避開日間 10–15 時、離開草叢竹林。
- 一般蚊子:範圍更廣(低中海拔、雨後、溪邊)。呈現時**合併成單一「蚊蟲警示」**,以小黑蚊為主軸、附一般蚊子一句提示,不分兩塊以免冗長。

### 連網增強:iNaturalist(選配)

生態區塊提供「看這附近的真實目擊」按鈕:
- 呼叫 iNaturalist 公開 API:`https://api.inaturalist.org/v1/observations?lat={lat}&lng={lon}&radius=5&locale=zh-TW&order_by=observed_on&per_page=20&photos=true`(支援 CORS)。
- 顯示近期真實觀察:物種中文名 + 縮圖。
- **離線或請求失敗 → 安靜隱藏此按鈕**,不影響離線的規則式內容。
- 標示「附近 N 公里的真實觀察」以區隔規則式內容。

## 模組劃分(介面清楚、可獨立測試)

- **`web/js/ecology.js`**——資料 + 邏輯,不碰 DOM:
  - `Ecology.habitatsFor(trail)` → `["低海拔闊葉林", "溪流"]`(環境帶判定,純函式)
  - `Ecology.speciesFor(trail)` → `{ mammal:[], bird:[], insect:[], herp:[], other:[] }`(取環境帶物種聯集)
  - `Ecology.biteRisk(altMeters, region, date, tags)` → `{ level, tips, seasonal }`(純函式,可單元測試)
  - `Ecology.nearbyObservations(lat, lon)` → `Promise<[{ name, thumbUrl, observedOn }]>`(連網,失敗回 null)
- **詳情頁呈現**——在詳情頁模組(`trails-detail.js` 或 app.js 詳情渲染處)新增「生態」區塊,呼叫上述介面組出 HTML。呈現與資料分離。

## 呈現(詳情頁「生態」區塊,與路況/設施/交通並列)

1. **蚊蟲警示**:等級色塊 + 一行防護建議 + 季節提示(當季才醒目)。
2. **常見動植物**:分類(哺乳🦌/鳥🐦/昆蟲🦋/兩爬🐸),每種 emoji + 中文名;標題註明「這個海拔帶常見會遇到的」。
3. **(有網路)真實目擊**:可展開,iNaturalist 近期觀察縮圖 + 名稱。

## 離線與 i18n

- 規則式內容(環境帶物種、蚊蟲警示)**完全離線**。
- iNaturalist 目擊為選配,離線隱藏。
- **翻譯**:區塊標題、蚊蟲警示語、防護建議、分類名(哺乳/鳥/昆蟲/兩爬)翻 25 語言;**物種名維持中文**(可附學名)。

## 測試策略

- 單元測試(`scripts/tests/test-fixes.js`):
  - `biteRisk`:低海拔中南部夏季 → high;高山任何季節 → none;北部冬季低海拔 → 降級;非當季 → seasonal=false。
  - `habitatsFor`:各海拔/水系標籤 → 正確環境帶(含多帶聯集)。
  - `speciesFor`:多環境帶步道 → 物種去重聯集。
- i18n:check.js H 規則守新中文字串——標題/警示語/分類名補進 i18n.js 字典(要 25 語言平行);**物種名維持中文,字串加進 `scripts/i18n-ignore.json`**(屬資料非 UI,比照步道名的處理)。
- 連網目擊:離線時按鈕隱藏(可 e2e 或手動驗證)。

## 非目標(YAGNI)

- 不做完整物種圖鑑/百科(只列常見代表種)。
- 不做使用者回報目擊、不做物種收集/成就。
- 物種名不翻 25 語言。
- 植物僅少量帶到(以動物/昆蟲/鳥為主)。
- 不接除 iNaturalist 外的其他生態 API(未來可加)。

## 風險與注意

- **可信度**:環境帶物種集合須基於可靠的台灣生態常識,寧可保守(列真正常見的代表種),不要為了豐富而編入罕見或不符海拔的物種。
- **小黑蚊季節**:依當下日期動態顯示,避免冬天嚇人或夏天漏警示。
- **iNaturalist 資料品質**:偏遠步道觀察少屬正常;都市近郊觀察多。按鈕文案要讓使用者理解這是「附近的真實記錄」,不是步道保證。
