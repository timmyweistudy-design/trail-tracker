# 翻譯抽查表

每個語言一份 CSV，用 Excel 或 Google 試算表直接打開。內容是畫面上最常出現的 200 句：
- 安全相關的 60 句排在最前面，標記為 ★。
- 其餘 140 句依出現次數排序。

請母語者這樣看：
1. 讀第二欄「目前譯文」。不自然、意思不對、太生硬的，在第三欄寫建議的說法。
2. 沒問題就留空。
3. 改好後把檔案寄回來，交給 Claude 套用到 `web/js/i18n/<語言>.js`。

重新產生（或加別的語言）：
```
node scripts/i18n-review.js en ja ko de
```

2026-10 第一次產生時，已經順手修掉這些錯：
- 日文：「封閉」譯成「閉店」，「林業署」譯成「林野庁」（日本的機關）。
- 韓文：「林業署」譯成「산림청」（韓國的機關）。
- 7 段難度說明全部 24 語重寫。例如日文、韓文把「海拔 2,000～3,000 公尺」誤譯成「距離」，「跟有經驗的人一起去」誤譯成「跟專家去」。
