# 免費與 PRO 的分界

原則：
- **安全相關一律免費。**
- 基本版是「記錄、找步道、陪伴」最基本的功能。
- 額外的福利、進階數據、外觀放在 PRO。

程式裡的閘門用 `_proGate()`（`web/js/review.js`）。這是 fail-closed：付費模組沒載入時一律擋。
升級面板的清單在 `web/js/premium.js`：
- `ALWAYS_FREE`：永遠免費
- `BENEFITS`：PRO 福利
- `COMPARE`：比較表

> 目前 `web/js/config.js` 的 `PERSONAL_MODE = true`（自用模式）：所有人都是 PRO。
> 正式上架前改成 `false`，下面的分界才會生效。

## 免費（基本）

- **記錄**：GPS 記錄、暫停、結算、隨手拍、小隊同行。
- **步道**：搜尋、篩選、詳情、天氣、海拔、生態、周邊、收藏 20 條。
- **夥伴**：成長、餵食、每日任務、每月挑戰、成就、登頂收集冊。
- **夥伴配件**：每月挑戰的「登山頭巾」免費。以前用果實換到的配件，訂閱到期後照樣能戴。
- **步道人氣**：近 7／30 天人數、熱度圖。
- **社群**：動態、貼文、留言、追蹤、揪團、通知；拜訪好友的夥伴、摸摸頭、送果實；加入山社（看排行、成員、動態）。
- **外觀**：淺色／深色／陽光高對比、字體大小。
- **資料**：雲端自動備份。
