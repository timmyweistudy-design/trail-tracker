# 新一輪 App 優化（2026-10-10 列出，未開工）

在現有功能上優化：付費牆、功能體驗、排版美化、效能、程式碼。夥伴專屬的 38 項另見 [pet-handoff.md](pet-handoff.md)，不在這裡。

**依據**（都是這次實測的）：
- 全站掃描 `scripts/ui-sweep.js`：中英文 × 兩種字級，按了 155 顆測試按鈕，**0 個 JS 錯誤**。
- 效能是在 CPU 降速 4 倍下量的：
  - 啟動 1.6 秒就緒，載入 63 支 script、98 個請求，解壓後 5.5 MB。
  - 最長卡頓 112 ms；切到夥伴分頁時卡 137 ms。
- 用「模擬免費用戶」截圖：PRO 彈窗高 2152 px，約 2.5 個螢幕。
- 把各分頁截圖逐一看過。

## A. 付費牆（使用者指定）
| # | 項目 | 做法 |
|---|---|---|
| A1 | **登頂收集冊改 PRO** | 「我的」那一排加 PRO 標籤，打開時要先過 PRO 檢查。免費用戶山頂照樣自動蓋章（資料不丟），打開時看到預覽：「已蓋 5 章，升級看完整收集冊」。升級後全部都在。同步改：升級彈窗、比較表、首次導覽那句、條款 |
| A2 | **PRO 彈窗重排** | ① 「安全功能永遠免費」分成三組，用圖示＋兩欄：<br>　- 出發前：登山計畫書、留守人、山頂天氣、林業署路況<br>　- 山上：偏離路線、天黑倒數、原路返回、高山提醒、低電量、求救卡<br>　- 互助：山友路況回報<br>② 把不是安全功能的「附近步道、離線 10 MB、鎖定畫面卡片」移到「免費也有」<br>③ 現在同一批功能講了兩次（功能卡 12 張＋比較表 18 列），合成一張有圖示的表<br>④ 方案和「免費試用」按鈕要不用捲就看得到<br>目標高度 ≤ 1.3 個螢幕 |
| A3 | 比較表補漏 | 口袋路線 3 組 vs 不限、表情貼 6 vs 30、登頂收集冊 |
| A4 | PRO 清單集中管理 | 現在約 30 處各自寫 `typeof Premium !== "undefined" && Premium.isOn()`。改成一份 PRO 功能清單，同時驅動彈窗、PRO 標籤、檢查。之後新增 PRO 功能只改一處，彈窗不會再漏（收集冊就是這樣漏掉的）。加測試：每個有檢查的功能都要在彈窗裡 |

## B. 功能體驗
| # | 項目 | 依據／做法 |
|---|---|---|
| B1 | 探索預設清單把暫停開放的排到後面 | 一打開，前兩張卡都是「暫停開放」（南澳古道、金瓜寮）。預設排序把封閉的沉到後面，標示保留 |
| B2 | 封閉步道的「在此步道開始記錄」 | 詳情頁寫著暫停開放，下面卻是大大的綠色開始鈕。改成按了先提醒「目前暫停開放」，按鈕也換成警示樣式 |
| B3 | 「我的」新用戶空狀態 | 0 筆紀錄時滿版都是 0.0。改成一張「走第一趟」引導卡（附近步道＋開始記錄），有紀錄才顯示統計 |
| B4 | 記錄地圖起始視角 | 一進記錄頁顯示整個台灣。改成上次位置／最近一條步道，有定位就跳到所在地 |
| B5 | 英文模式的好友夥伴名 | 好友沒取名時，預設名是中文物種名（「雲豹 came by today」）。預設名要跟著語言翻 |
