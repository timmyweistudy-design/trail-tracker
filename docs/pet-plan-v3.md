| 項目 | 做法 | 驗收 |

| **原23 雙向串門子** | 朋友的夥伴來過之後，夥伴頁出現「回訪」：你的夥伴走去對方舞台（拜訪卡裡），兩隻一起玩一次松果；雙方各記一筆日記（「去 XX 家玩」）；每天每位好友一次 | 測試：回訪動畫兩隻不疊位、不卡住；同一天第二次不行 |
| **原25 送小東西** | 伺服器端交易：`give_pet_item(to, item)` RPC（security definer）＝檢查送的人真的有、同一件不重複送、對方沒有才收、寫通知；**送出是一次交易**（扣掉＋給對方同時成功或同時失敗）；離線時按鈕停用，不做本機排隊（避免重複） | SQL 測試：沒有的送不出、重送無效、對方已有不重複；前端：送出後兩邊收藏冊都對 |
| **原24 地圖上隊友的夥伴** | 已有靜態夥伴 → 戴帽子＋配件、依種類動（滾、爬、飛、游，沿用自己地圖夥伴的 CSS）；`team_presence.pet` 擴成 `{stage, hat, acc}`（小 JSON，每 8 秒那次一起送，不多發請求） | 測試：隊友的標記戴配件；減少動態效果時不動 |
| 社群安全 | 送小東西、回訪都走既有的封鎖／檢舉規則（封鎖的人送不了、看不到） | SQL 測試：封鎖後 RPC 回 false |
