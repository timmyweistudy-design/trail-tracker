- **待辦**：S1～S6 做完、使用者在手機上聽過都說可以，再把 `web/js/pet.js` 的 `PET_SOUND_READY` 改成 `true`。

## 1. 為什麼現在聽起來「機械、不真實」（查過的原因）
| 原因 | 證據 |
|---|---|
| **音質被壓壞** | 22 個檔案全部壓成 22 kHz 單聲道、約 48 kbps。8 kHz 以上的頻率全被切掉，咬蘋果的「脆」、葉子的「沙沙」都沒了，像隔著電話聽 |
| **同一段錄音硬拉音高** | 老虎、龍用同一段咀嚼聲放慢到 0.55～0.64 倍。放慢會變悶、拖長，有「機器人」感 |
| **一個動作只有一段聲音** | 每次都是同一段，只隨機 ±4% 音高，耳朵很快聽出是重複播放 |
| **第一次觸發是合成音** | 檔案還沒載好時，退回程式合成的「嗶」聲（正弦波），最機械的就是這個 |
| **只有單一音效，沒有層次** | 果實掉下來只有一聲「啵」：沒有劃過空氣、落在草地、滾一下的組合；沒有任何環境音，所以每個音效都像飄在真空裡 |

## 2. 原則
1. **真的錄音**，不用合成；第一次還沒載好就安靜，不再放合成音。
2. **每個動作 3～5 段不同錄音**，隨機挑、不連續重複，音高只在 ±6% 內微調。不同物種用不同的錄音，不靠放慢。
3. **疊層**：一個事件由 2～3 層組成。例如果實掉落＝劃過空氣（很輕）＋落地（主體）＋滾動或葉子聲（尾巴）。
4. **環境音當底**：舞台本來就有時段（清晨、白天、黃昏、夜晚）、天氣（晴、雨、風、雪）、近親物種（森林、海、高山），環境音跟著換。音效有了空間感，才不會像飄在真空。
5. **音質**：44.1 kHz。音效用單聲道 96 kbps AAC；環境音和音樂用立體聲 96～128 kbps。
6. **我聽不到聲音**：所有候選做成手機上的「試聽板」，**由使用者選**。我只負責找素材、剪短、對齊音量、接程式。

## 4. 環境音（跟舞台狀態連動）
| 舞台狀態 | 環境音 | 候選來源 |
|---|---|---|
| 清晨、白天（森林） | 鳥叫、遠處溪水，非常小聲 | 清晨林間鳥叫（353311、288899） |
| 黃昏 | 鳥聲變少、蟲聲開始 | 用白天和夜晚兩段交叉淡入淡出 |
| 夜晚 | 蟋蟀、蟲鳴 | 夜晚蟋蟀（522299、175020） |
| 下雨 | 雨打樹葉 | 另外再找（這次的搜尋沒抓到合適的） |
| 起風 | 風聲當底，陣風疊在上面 | 同第 3 節的風 |
| 海風近親 | 海浪 | 另外再找 |
| 高山近親 | 空曠的風、偶爾一隻鳥 | 冬林輕風（352436） |
| 瀑布、溪邊步道走完回來 | 溪流 | 山澗（262647） |

環境音的規格：
- 30～60 秒的循環，頭尾交叉淡化，聽不出接縫。
- 音量很低（約音效的 25%）。
- 切換時花 2 秒淡入淡出。
- 夥伴頁看不到（捲走、切分頁、App 到背景）就停。

## 5. 背景音樂
**建議做法**：
- 只在**夥伴頁**放，音量低（約音效的 30%），預設關，使用者自己打開。
- **記錄健行時絕對不放**：山上要聽環境、聽提示音。
- 選曲走「森林、溫暖、手作感」：木吉他、卡林巴琴、輕鋼琴。準備 2～3 首各 1.5～3 分鐘的曲子輪播，依時段挑：白天輕快、夜晚安靜。

**來源（依建議順序）**：
1. **OpenGameArt 的 CC0 音樂**：可商用、不必標示。實際查到有平靜曲風的作品（例如 Happy Lullaby、November Snow、JRPG Pack 4 Calm），但要逐首確認授權寫的是 CC0。
2. **Freesound 的 CC0 音樂片段**：吉他、鋼琴的循環片段，可以自己串成曲子。
3. **Pixabay Music**：可商用、不必標示，可以放進 App，但不能把音樂單獨拿去散布。授權條款要存檔備查。
4. 不用：CC BY-NC（不可商用）、來源不明的「免費音樂」。

**跟使用者自己的音樂並存（重要）**：
- 很多人健行時會聽 Podcast 或音樂，App 的聲音不能把它們停掉。
- 用瀏覽器的 Audio Session API，設成 `navigator.audioSession.type = "ambient"`：可以跟其他 App 的聲音一起放，iPhone 打開靜音鍵時也會靜音。
- Safari 16.4 以上支援，iOS 15 舊機會退回預設行為。
- App 內（WKWebView）的實際行為**要在手機上驗證**；不行的話改用原生設定 AVAudioSession 的 ambient 類別。

## 6. 混音與程式
- **三條音量線**：音效、環境音、音樂各一個總音量。
  - 重要音效（進化、收禮物）響的時候，環境音和音樂自動壓低 40%，0.8 秒後回來。
- **聲音池**：每個事件一組錄音，隨機挑、不連續重複同一段，音高 ±6%、音量 ±10%。
- **不再放合成音**：第一次還沒載好就安靜。進夥伴頁時先預載「吃、掉落、摸頭」這幾個最常用的。
- **檔案大小**：
  - 音效約 40 段 × 15 KB ≈ 600 KB。
  - 環境音 6 段 × 400 KB ≈ 2.4 MB。
  - 音樂 3 首 × 1.5 MB ≈ 4.5 MB。
  - 音效和環境音只在第一次進夥伴頁時下載；音樂只有打開開關才下載。
  - App 版直接內建，網頁版由 Service Worker 快取。
- **省電**：看不到夥伴頁就停掉環境音和音樂的迴圈；裝置要求減少動態時，環境音預設關。

## 7. 設定
「活力和親密」說明裡的開關，從一個變三個：
- **夥伴音效**：預設開。
- **環境音**：預設開，很小聲。
- **背景音樂**：預設關。

每個都有小滑桿調音量。

## 8. 試聽流程（我聽不到，這是關鍵）
1. 測試面板加「🎧 音效試聽板」：每個時機列出 3～5 個候選，按一下播、按「選這個」記下來。可以疊環境音一起聽，也可以模擬「三顆果實連續掉落」的整串效果。
2. 你在手機上選完，按「複製結果」，貼給我。
3. 我照你選的定稿、剪短、對齊音量、接進程式，再請你聽一次整體（餵食一輪、摸頭、起風、夜晚）。
4. 哪個不對就說，換下一個候選。

## 9. 授權
- CC0 優先：可商用、不必標示，但 `CREDITS.md` 和第三方授權頁照樣記來源。
- CC BY 可以用，但要在第三方授權頁標作者。
- **不用 NC（不可商用）**。
- 背景音樂的授權逐首存檔。
- 第三方授權頁補上「環境音」「背景音樂」兩節。

## 10. 階段
| 階段 | 內容 | 驗收 |
|---|---|---|
| S1 | 引擎改版：三條音量線、聲音池、不再放合成音、環境音迴圈、Audio Session 設成 ambient | 測試：不連續重複、看不到就停、記錄中不放音樂 |
| S2 | 找素材：每個時機 3～5 個候選，用 44.1 kHz 重新處理、對齊音量、剪掉頭尾 | 檔案規格檢查（取樣率、音量、長度） |

| S4 | 接進動作：果實掉落三層、吃東西依物種、風跟天氣、環境音跟時段 | 測試：每個時機都有聲音、層次正確 |
| S5 | 背景音樂：選曲、只在夥伴頁、預設關、壓低規則 | 你在手機上聽：跟 Podcast 一起放不會被停掉 |
| S6 | 設定三個開關＋音量；第三方授權頁、`CREDITS.md`；你說可以就把 `PET_SOUND_READY` 改成 true | 全套測試＋全站掃描 |
